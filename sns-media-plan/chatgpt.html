2. 読者の整理と媒体の評価基準

読者は自費で月3万円程度のAI課金を検討する個人で、30〜40代男性を中心とは仮定しない。「用途を探す」「プランを比較する」「課金を継続・乗り換える」という状態を扱う。同じ人が行き来するため、媒体ごとに固定した人物像を割り当てない。

判断材料は成果物、経過時間、人の実作業・介入、使用量。仕事では使える品質、副業では再現性、創作では修正の自由度、学習では正確さと理解への寄与を示す。用途で入口を変えても四項目は共通とし、文章・調査では修正箇所や根拠確認を見せる。

パーソル総研（S1）では生成AI利用就業者8,373人のうち個人課金者は22.5％だが、課金額はこの数字から分からない。内閣府調査（S2）では生成AI利用者がよく使うサービスの上位にYouTubeがある。ただし性年代を均等に割り付けた標本で、人口代表値でも月3万円の検討者調査でもない。対象読者の媒体別分布を直接測る資料は確認できず、利用者総数で順位を決めない。

評価は検索・発見、条件を含む理解、再訪、制作・更新負担。到達と再訪を同程度に重視する。各媒体の文章・写真・動画を比較し、順位は分析者の判断とする。制作負担を日時の推奨根拠には使わない。

3. 媒体ランキングの根拠

1位：YouTube／主軸として採用。 検索・推薦（S3）で用途から探す人と偶然見る人の双方に届く経路がある。通常動画で操作・修正・介入を連続して示し、再生リストで次回へつなぐ設計を評価した。制作負担と視聴時間の要求が弱点で、検索需要・再訪効果は未実証。

同率2位：Instagram／採用。 リールは成果物や操作の違いを動きで見せ、カルーセルは条件・数値を自分の速度で比べる。実演と読み比べを同じ媒体内で届けるため、両形式を採用する。MetaのTrial Reels（S17）には非フォロワーに先に見せる機能があり、Metricool調査（S16）もリールの発見とカルーセルの保存という役割を支持する。ただし日本のAI比較における成果保証ではなく、両形式とも新規発見・再訪に使える。

同率2位：TikTok／採用。 推薦・検索・フォローの経路（S5）があり、用途をまだ言語化していない人にも成果物から説明を始められる。写真カルーセル（S5）もあるため、「数字をゆっくり読めない媒体」とは評価しない。成果物・操作・人間の修正を連続して示せるため比較動画を選ぶ。条件を急いで流すと判断材料が届かないことが弱点だが、これはShortsにも共通する。Instagramとの到達・継続の優劣は未確認なので同順位とした。

同率2位：Threads／条件付き。 トピック・フィードで発見し、最大1万字の添付（S6）・画像・動画で条件を示せる。返信も接点になるが、長文の編集と対話の負担がある。初期不採用は機能不足ではなく運用範囲の判断。

同率2位：X／条件付き。 推薦・フォロー中表示（S7）、画像・引用・返信で発見と再接触を設計できる。本文の文字数制約を比較画像やスレッドで補う必要がある。対象読者の多さやThreads等への優位は未確認。

6位：Pinterest／当面見送り。 検索・保存（S8）で比較図を発見・再参照でき、動画Pinで実演、ボードのフォローで継続接点も作れる。創作以外にも適用できる。ただし公式の制作手順では、PCから複数画像を上げると別々のPinになり、アプリでまとめると動画になる。比較条件を一続きの静止画として読ませる今回の編集案には、図の再構成が必要と判断した。順位の確信は低く、動画中心なら差は縮まる。情報の陳腐化や継続効果の未実証は全媒体共通である。

初期はYouTube・Instagram・TikTokに絞り、各媒体内で実演と判断材料を届ける。Threads・Xを外すのは同時運用の範囲を絞る判断で、成果が低いと実証されたためではない。文章と画像を一緒に読む形式を重視するなら、InstagramをThreadsまたはXに替える余地がある。

4. 投稿形式・頻度・曜日・時間帯の根拠

週2件の新規検証から、note2本、通常動画1本、Shorts・TikTok各2本、Instagramはリール1本とカルーセル1本を出す。週2回のInstagram接点で実演と読み比べを両方届ける配分で、1対1が最適という実測根拠はない。頻度は継続用の仮案であり、曜日・時刻の根拠とは別である。YouTube公式（S3）も毎週投稿を必須とはしていない。

リール・短尺は60〜90秒を目安に、完成物、同じ指示で生じた差、人間の修正、判断の留保まで示す。カルーセルは条件・品質・時間・介入・使用量を6枚程度で読み比べる。動画に表を読み切れない速さで流さない。Instagramに動画を置く価値は、TikTokを使わない閲覧者にも実演が届くことにある。既存動画の転載だけで済ませず、字幕・表紙・説明の伝わり方を整える。通常動画は一つの検証を6〜10分で詳しく見せる。尺と枚数は仮説である。

選定の順序は、視聴・閲覧側の資料→今回の内容への推論→具体的な初期案とする。 国内利用調査を時刻の基準にし、形式別の投稿実績も参照する。曜日は国内の直接資料が乏しいため海外集計を弱い補助情報にする。資料間で違う結果が出る場合は比較候補を残す。海外の現地時刻集計に時差を足して日本の実証結果に変えることはしない。曜日と時刻を別資料から組み合わせた枠は、組み合わせ自体が未検証である。

国内調査（S9）は一般SNS利用者2,903人への複数回答で、主要5媒体の利用は夜21〜22時台に多い。ただし投稿成果でもAI課金検討者限定でもない。夜を勧める理由を「30〜40代男性が仕事後に見るから」とはしない。朝の通勤も対象全員に当てはめず、朝を比較候補として残す。

6. 不確実な点と、運用開始後に検証すべき項目

公式仕様は事実、外部調査は傾向、順位は推論、本数・日時は仮説とする。月3万円の検討者への到達・継続効果は未実証。低額プラン等と比較せず絶対的な費用対効果を断定せず、使用枠％もサービス間の共通資源量に換算しない。

開始後は到達・理解・継続を分ける。動画は結果提示部分までの維持、画像は保存や条件に関する質問、継続は次の検証への移動やYouTubeの再訪区分（S12）を確認する。保存・反応は理解の代理にすぎず、直接測れない部分は未測定とする。コア視聴者は半年超の継続を要する定義なので短期評価に使わない。

4週目に工数と説明不足、8週目に継続方針を点検する。期間だけで効果を証明せず、媒体間の表示・再生数も単純比較しない。週40時間を超える場合は形式・本数を再設計する。Threads・Xは既存枠と1媒体ずつ入れ替える。

時間帯を比べる際は、両条件とも前週までに完成した素材を使う。同じ曜日・形式で類似題材を交互に割り当て、公開後7日など観察期間をそろえる。試験用に具体的な時刻を固定しても、それが最適という意味ではない。曜日を比べる試験は時間帯を固定し、一度に両方を変えない。題材差が残るので因果の証明とはしない。比較試験では投稿内で判断材料を完結させ、両条件とも原典リンクを付けず、原典の公開順の差を持ち込まない。投稿・確認は予約または作業枠の振替で収め、週2件・各6時間を超えて準備在庫を追加制作しない。
